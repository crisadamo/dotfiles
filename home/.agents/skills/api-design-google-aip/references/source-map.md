# General AIP source map

This skill is an original operational summary derived from the [General Google API Improvement Proposals](https://google.aip.dev/general). The AIP repository is published under the Creative Commons Attribution 4.0 license, with code samples under Apache 2.0. This skill does not reproduce the AIPs in full and does not imply Google endorsement.

The source catalog was verified on 2026-08-18 from commit [`23e176e7333ea3bc6b085f9950a5da03d2bbfc72`](https://github.com/aip-dev/google.aip.dev/commit/23e176e7333ea3bc6b085f9950a5da03d2bbfc72). Check the live AIP before making a compatibility-sensitive decision.

Unless noted otherwise, every AIP below was **approved** in that snapshot.
