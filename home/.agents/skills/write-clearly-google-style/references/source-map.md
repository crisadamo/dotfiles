# Canonical Google guide source map

This skill is an original operational summary derived from the [Google developer documentation style guide](https://developers.google.com/style), which Google publishes under the Creative Commons Attribution 4.0 license. It does not reproduce the guide in full and does not imply Google endorsement.

The source hierarchy and page catalog were verified on 2026-08-18. The guide changes frequently. For policy-sensitive work, terminology disputes, or an explicit request for the latest rule, check [What's new](https://developers.google.com/style/whats-new) and the relevant live page.

## Start here

- [About this guide](https://developers.google.com/style/): authority order, scope, and deliberate exceptions.
- [Highlights](https://developers.google.com/style/highlights): the high-value rules.
